# L-Player

Core:
1. Player Video/Audio menggunakan libmpv rust yg nantinya di run pakai package flutter_rust_bridge
2. MultiOS (MacOS, Linux, Android, iOS) pertama di Linux dulu.

Features:
1. User dapat menambah/remove list video/audio drag n drop.
2. Memainkan semua list secara default berurutan, bisa shuffle, list bisa diatur geser atas atau bawah.
3. Subtitle on/off, bila file subtitle terpisah cukup drag n drop ke list video/audio.
4. Bisa memainkan video/audio via internet/url.
5. Player bisa di slider, percepat forward or backward, bisa percepat 10s, 5s, 2s, 1s, 0,5s, button next prev, pause, play, and stop memperlambat/mempercepat.
6. Volume Slider.
